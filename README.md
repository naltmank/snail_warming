# Corallivore impacts on corals under ocean warming

Contains the data and code for Altman-Kurosaki NT, Hay ME (In Press). Corallivore impacts on corals under ocean warming depend on both consumer and prey responses to rising temperatures. Mar Ecol Prog Ser.

Repo must be cloned as a .Rproj in order for pathing to work correctly. Chunks are titled according to the broad analyses and plots they cover.

#### Data ####
1. coral_weights.csv - used for analyses assessing relative mass change in terms of wet weight over the course of the experiment.

2. poc_wax_dipping.csv - contains the wax dip weights for calculating surface area-corrected tissue biomass.

3. pocillopora_biomass.csv - contains the tissue biomass for calculating surface area-corrected tissue biomass.

4. pocillopora_wax_dipped_corals_images.csv - contains the imageJ data used to correct tissue biomass estimates according to Pocillopora planar area.

5. porites_biomass.csv - contains data needed to calculate P. rus surface area-corrected tissue biomass.

6. snail_choice_assay.csv - contains data from the initial choice assay run to determine snail feeding preferences. 

7. snail_feeding.csv - contains the data describing the occurrence of observed snail feeding on a coral fragment over the course of the experiment (binary).

8. snail_respo.csv - contains the snail respirometry data.

9. tissue_loss_image_analysis.csv - contains the data from imageJ used to correct tissue biomass estimates according to the amount of living tissue left on the corals at the end of the experiment.
